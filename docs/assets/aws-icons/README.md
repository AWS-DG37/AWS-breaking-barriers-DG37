# AWS architecture icons

These SVG files are unchanged copies from the official AWS Architecture Icons set
(release 30 January 2026), taken from the `aws-icons@3.3.0` npm package, which
repackages that set. `docs/aws-deployment.html` uses them.

AWS permits the use of these icons in architecture diagrams. See the terms at
https://aws.amazon.com/architecture/icons/. Do not edit the files. To add an icon,
copy it from the same package without changes.
