What this shows, and what it leaves out

  • The diagram shows the AWS resources that run today. It shows the delivery path because every merge to main uses it.
  • Two agent paths call Amazon Bedrock. The MEL agent graph runs inside the console on EC2, under the console spend cap; the host role allows OpenAI GPT-6 Luna (Responses API), Anthropic Claude Haiku 4.5 and Amazon Nova Lite (Converse API). The Agents tab invokes the Strands survey agents on Bedrock AgentCore Runtime (FieldEchoAgentCore_melSurveyAgent); its role allows Anthropic Claude and OpenAI GPT generators, Claude verifiers and the Google Gemma translator.
  • Every merge to main also releases the agent code: CI uploads an exact-SHA CodeZip to S3 and updates the AgentCore runtime (deploy/agentcore.py).
  • template.yaml describes a larger serverless stack (Lambda, API Gateway, Fargate, RDS, S3). That stack is not deployed, so it is not on the diagram.
  • The voice survey runs on GitHub Pages with ElevenLabs recordings. It does not use AWS.
  • Slide exports: light and dark. The dark version is also slide 4 of the team talk. Add #dark or #light to this page's address to force a theme. Update steps are in a comment at the top of this file.
