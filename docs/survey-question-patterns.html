Survey Question Patterns

The 95 surveys in golden_set.jsonl (version 1) follow one fixed template per resolution type. No Digital Green document states these templates. This page reads them out of the data.

The Vision document defines the golden dataset as "insights with expected high-quality surveys, used for evaluation", so these templates are what the evaluation compares against. They are still evidence, not a spec. The brief's own worked scenarios use different questions (see the comparison below). Confirm with Digital Green before the team treats this as a question library.

Check before use

  • No follow-up flags. The brief requires a follow_up reason on bad answers, for example "more insects than before" or "the cow is worse". The golden answers "Worse" and "Could not reach" carry none.
  • show_if is not in the schema. The golden set shows "If not, what stopped you?" only when q1 is not "Yes". survey.schema.json has no field for a condition.
  • English only. All golden questions are English. The farmer gets the copy in the insight's conversation_language, mostly hi-IN, and Hindi answer labels must still fit 20 characters.
  • Different shape. Golden items use id, text and plain option strings. survey.schema.json uses item_id, type, prompt and option objects with value and label.
  • Version 1. Digital Green can update the golden set during the event. Rebuild this page when it changes.
